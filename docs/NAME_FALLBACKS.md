# Name fallbacks — backup titles for Kestrel Heavy

> **NOT LEGAL CLEARANCE.** A quick public screen by an agent on 2026-10-12 (USPTO mirrors, App Store search, web search). Before using any name, Trevor or counsel should run a full search on tmsearch.uspto.gov (classes 9, 28, 41) and a proper clearance.

## Context
The game stays **Kestrel Heavy**. Nothing is renamed in code or on the store. These are backups in case the name becomes a problem. Known nearby risks (see NAME_REVIEW.md): **Kestrel Games** (an indie space-game studio), **Easy Aerial's "Kestrel Heavy"** drone, and several class 9 KESTREL software marks. Every fallback therefore avoids the "Kestrel" root, plus real vehicles, companies and programs.

## Notes
- Plumeline and Thrustwright are coined words, so they are the strongest picks for a trademark. Pad to Orbit says most clearly what the game is, but it's weak as a mark.
- App Store titles can add a subtitle, for example "Plumeline: Rocket Launch".
- The USPTO results come from web search over public mirrors (uspto.report, furm.com, markinton.com). tmsearch.uspto.gov needs the browser UI and wasn't queried directly. A missing result there isn't proof that no mark exists.

## Method
1. Brainstormed about 10 names, then dropped any with real-vehicle, company or Kestrel ties.
2. App Store: `https://itunes.apple.com/search?term=<name>&entity=software&country=us`.
3. Web and trademark: web searches for each exact phrase plus "trademark" and "game".
4. Risk rating: Low = nothing found; Med = the same or a similar name in use outside games, or a crowded root; High = the same name held by a game company or under class 9/28/41 marks.
