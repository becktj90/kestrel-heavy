# Kestrel Heavy: Music Cue Sheet

Owner: Kestrel Sound (X2). Companion to `docs/MUSIC_BIBLE.md` (motif, mix targets, engine). Triggers use flight-bus event names from `docs/FLIGHT_EVENTS.md` where they exist; others are UI/game states.

Conventions: tempos 72–96 BPM, 4/4. **Q** = bar-quantized (next bar line), **Ph** = end of 4- or 8-bar phrase, **Imm** = immediate (stingers only). Layers L0 sub/pulse, L1 pad/harmony, L2 ostinato/rhythm, L3 melody/brass/perc (Bible §6.2). Every cue obeys narration ducking (×0.35) and alarm exclusion (Bible §4). Sketch = file in `tools/music/out/`.

## Global rules
- No cue may start or add L3 while an alarm is active; stingers wait for alarms to clear (Bible §4).
- Narration always ducks music to ×0.35 with 250 ms release (S1).
- All loops are cut to exact bar lengths; tails rendered separately for clean Q exits.
- Every cue file must have a `MUSIC_LICENSES.md` row before merge.
