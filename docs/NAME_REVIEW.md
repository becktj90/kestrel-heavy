## Kestrel Heavy
| Check | Finding |
|---|---|
| App Store "kestrel heavy" | No app with this name. Only a bird reference app. |
| App Store "kestrel" | ~14 apps, none games: **Kestrel LiNK / KestrelMet / LiNK Ballistics (Nielsen-Kellerman)** weather/ballistics meters, Kestrel bird ID, reading app, VPN, finance/business tools. |
| USPTO (via mirrors) | Several KESTREL word marks in **class 9 software** for unrelated goods: Kestrel 360 (blockchain securities info, Ser. 97617566), Kestrel Technologies (stock trading software, Reg. 2092161 — **dead/cancelled**), LUMI AI (AI agents, Ser. 99487467 — **abandoned 2026-07-13**). Nielsen-Kellerman very likely holds KESTREL marks for weather meters (class 9) — not verified live. **No KESTREL HEAVY mark and no KESTREL mark for game software found.** |
| Web | "Kestrel Heavy Barrel/Stock/Grip" are weapon-part item names inside the video game *Off The Grid* (item names, not a title or brand). ATSpace (Australia) flies a real sounding rocket named **Kestrel I** (orbital Kestrel V planned). SpaceX's Falcon 1 upper-stage engine was named **Kestrel** (historical), and "X Heavy" echoes the Falcon Heavy naming pattern. |

**Verdict: AMBER-GREEN — keep "Kestrel Heavy" provisionally.** No identical mark or app found; "Kestrel" is a crowded, dictionary (bird) term, so the risk is in the space-industry associations, not a blocking registration. Mitigations: never use real rocket/company trade dress; keep the "original fiction, not affiliated with any launch provider" line in the description; avoid "Falcon"-style imagery or wording. Counsel should confirm no live KESTREL mark in class 9 for games before 1.0 ships. Not filing a trademark costs $0; filing (~$350/class) is Trevor's call.
