# Golden vectors

Generated by `node tools/export-golden.mjs` from the JS reference implementation in `web/js`.
Do not edit by hand; `tests/catalogs-json.test.cjs` regenerates them into a temp dir and fails on drift.

Every file is `{ generatedBy, tolerance, count, cases[] }`. `index.json` lists the counts.

| File | Covers | Tolerance |
|---|---|---|
| atmosphere.json | ISA 1976 T, p, rho, a, geopotential (−0.5 to 250 km) | rel 1e-9 |
| rocket-eq.json | Tsiolkovsky deltaV, massFlow, ispAt, thrustAt, burnTime | rel 1e-9 |
| aero-gravity-earth.json | cdMach, dragForce, gravityAccel, siteRotationSpeed | rel 1e-9 |
| orbit.json | orbitalElements (elliptic + hyperbolic), circularVelocity | rel 1e-9 (non-finite as strings) |
| vehicle.json | per preset: stage/strap-on/vehicle mass, toSimStages, baseCd, referenceDiameter, idealDeltaV, tank sizing, serialStages, requiredDeltaV | rel 1e-9 |
| simulate.json | simulate(): medium lifter (vacuum, 200 km, overloaded) + every preset; outcome, events, maxQ, orbit, losses, samples | rel 1e-6 (libm ulp drift over thousands of RK4 steps); event types/order exact |
| catalog-flight.json | every engine and every preset: ascent, staging, drag/max-Q, orbit determination | per quantity in docs/PHYSICS.md (absolute and relative). Harness: `tests/golden-harness.test.cjs` |
| economy.json | priceDesign (fresh + with learning/dev done), reliabilityOf, engine dev/batch cost, learning factor, clusterReliability | money exact (integers), reliability rel 1e-12 |
| vehicle-migrate.json | migrateDesign v0→v1 (no v2 schema) | structural equality |
| save-store.json | save envelopes, base-36 ids, native key policy | exact |

`catalog-flight.json` is regenerated by the same command as the other files: `npm run gen:golden` (`node tools/export-golden.mjs`). Do not hand-edit it. The numeric bands are not copied into the JSON; the harness reads them from `docs/PHYSICS.md`.
