# Golden vectors

Generated by `node tools/export-golden.mjs` from the JS reference implementation in `web/js`.
Do not edit by hand; `tests/catalogs-json.test.cjs` regenerates them into a temp dir and fails on drift.

Every file is `{ generatedBy, tolerance, count, cases[] }`. `index.json` lists the counts.

| File | Cases | Covers | Tolerance |
|---|---:|---|---|
| atmosphere.json | 21 | ISA 1976 T, p, rho, a, geopotential (−0.5 to 250 km) | rel 1e-9 |
| rocket-eq.json | 16 | Tsiolkovsky deltaV, massFlow, ispAt, thrustAt, burnTime | rel 1e-9 |
| aero-gravity-earth.json | 17 | cdMach, dragForce, gravityAccel, siteRotationSpeed | rel 1e-9 |
| orbit.json | 9 | orbitalElements (elliptic + hyperbolic), circularVelocity | rel 1e-9 (non-finite as strings) |
| vehicle.json | 10 | per preset: stage/strap-on/vehicle mass, toSimStages, baseCd, referenceDiameter, idealDeltaV, tank sizing, serialStages, requiredDeltaV | rel 1e-9 |
| simulate.json | 13 | simulate(): medium lifter (vacuum, 200 km, overloaded) + every preset; outcome, events, maxQ, orbit, losses, samples | rel 1e-6 (libm ulp drift over thousands of RK4 steps); event types/order exact |
| economy.json | 67 | priceDesign (fresh + with learning/dev done), reliabilityOf, engine dev/batch cost, learning factor, clusterReliability | money exact (integers), reliability rel 1e-12 |
| catalog-flight.json | 100 | every engine and every preset: ascent, staging, drag/max-Q, orbit determination | per quantity in docs/PHYSICS.md (absolute and relative). Harness: `tests/golden-harness.test.cjs` |

| steer.json | 262 | expo thumb-steer curve, sensitivity clamp, compact full-scale | rel 1e-9 |

Rows follow `index.json` order (the order `tools/export-golden.mjs` writes them). `tests/golden-readme.test.cjs` fails if a file is missing, listed twice, out of order, or has the wrong case count — merge conflicts here used to silently drop rows. Regenerate data with `npm run gen:golden`; `catalog-flight.json` bands are read from `docs/PHYSICS.md` by `tests/golden-harness.test.cjs`.
